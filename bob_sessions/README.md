# Bob Session Reports

Per the hackathon rules (`CLAUDE.md` §2), this folder must contain your exported IBM Bob IDE task session reports — required for judging eligibility.

These have to come from actual Bob IDE usage; they can't be generated by another tool. After each significant task in Bob (Plan, Code, Advanced, Ask, or Orchestrator mode), export the session report and drop it here, e.g.:

```
bob_sessions/
├── session_001_setup.json
├── session_002_prr_engine.json
└── session_003_ui.json
```
